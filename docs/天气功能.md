# 今日穿衣参考

登录后在衣橱首页选择城市，即可查看当前气温、体感温度、当天最低/最高温和最高降雨概率。穿衣建议按体感温度、温差和降雨/降雪条件生成，是规则提醒，不是 AI 衣橱单品推荐。

支持常用城市快捷选择和城市搜索；同名城市显示省份/国家供确认。城市选择保存在当前浏览器，无需定位权限或数据库改动。未选城市时不请求天气。

使用 Open-Meteo 非商业接口，无需新增账号、API Key 或环境变量。城市搜索与天气请求直接由浏览器发起，服务商会收到查询城市/坐标及常规网络请求信息。页面提供数据来源链接。

请求超时 12 秒后显示中文提示，支持重试或切换城市。切换城市时取消旧请求，避免结果错配；页面打开期间每 15 分钟重新请求，也可手动刷新。缺失降雨概率显示暂无数据，不用 0 代替。显示城市当地日期与天气数据时间。

接口文档：https://open-meteo.com/en/docs ，https://open-meteo.com/en/docs/geocoding-api 。商业使用前需核对服务商当前许可和套餐。

验证：自动化测试覆盖缺失数据、零度、城市校验、天气与穿衣建议、请求参数、请求失败与取消。应在用户手机网络下进一步验证服务可达性。
